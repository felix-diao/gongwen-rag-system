## 1. 系统简介

### 1.1 系统概述

AI 文档助手系统是一个智能办公文档处理平台，为您提供以下核心功能：

- **智能公文写作**：AI 自动生成符合规范的公文文档
- **会议助手**：音频转写、会议纪要自动生成
- **知识库管理**：文档上传、智能检索
- **会话历史**：问答记录管理、知识沉淀
- **Prompt 管理**：提示词模板定制

### 1.2 系统入口

系统提供两个功能入口：

| 入口 | 功能模块 | URL路径 |
|------|----------|----------|
| **AI 公文写作** | 公文生成、知识库、Prompt 管理、会话历史 | /doc/* |
| **AI 会议助手** | 会议管理、音频转写、纪要生成 | /meeting/* |

**入口选择**：
- 访问系统根路径 `/` 进入 Landing 页
- 选择对应入口进入功能模块
- 不同入口显示不同的功能菜单

### 1.3 用户角色

| 角色 | 权限说明 |
|------|----------|
| **管理员** | 管理所有用户、创建公有知识库、管理公有 Prompt 模板 |
| **普通用户** | 管理个人资源、使用公有资源、创建私有资源 |

## 2. 快速入门

### 2.1 登录系统

#### 2.1.1 方式一：用户名密码登录

1. 打开系统首页，选择功能入口（公文写作或会议助手）

## 3. 公文写作模块

### 3.1 功能入口

进入「AI 公文生成器」页面开始写作。

路径：`/doc/AI/document-writer`

### 3.2 公文类型

系统支持以下公文类型：

| 类型 | 名称 | 适用场景 |
|------|------|----------|
| **通知** | notice | 发布通知、安排事项 |
| **公告** | bulletin | 重要事项公告 |
| **请示** | request | 向上级请示文件 |
| **报告** | report | 工作报告、总结报告 |
| **信函** | letter | 公务信函 |
| **会议纪要** | meeting | 会议记录文件 |

### 3.3 公文写作流程

#### 步骤一：填写基本信息

| 输入项 | 说明 | 是否必填 |
|--------|------|----------|
| **公文标题** | 文档标题 | 必填 |
| **需求描述** | 公文内容和要求 | 必填 |
| **公文类型** | 选择公文类型 | 必填 |
| **语气风格** | 正式/专业/随意 | 可选 |
| **Prompt 模板** | 选择提示词模板 | 可选 |
| **知识库** | 选择参考知识库 | 可选 |

#### 步骤二：生成公文

1. 填写需求描述，详细说明公文内容
2. 选择公文类型和语气风格
3. 可选择 Prompt 模板指导生成风格
4. 可选择知识库提供参考资料
5. 点击「生成」按钮

系统将自动生成公文内容，显示在编辑区。

#### 步骤三：编辑优化

1. 查看生成的公文内容
2. 可手动编辑修改
3. 点击「优化」按钮进行 AI 优化
4. 输入优化要求，如「精简语言」「增加细节」

#### 步骤四：导出文档

支持多种导出格式：

| 格式 | 说明 |
|------|------|
| **PDF** | 导出 PDF 文件，符合公文格式标准 |
| **Word** | 导出 DOCX 文件，可继续编辑 |
| **文本** | 导出 TXT 文件，纯文本格式 |

### 3.4 AI 率检测

系统提供 AI 率检测功能，评估内容的 AI 生成概率：

- 检测结果为 0-100 分值
- 分值越高表示 AI 生成特征越明显
- 可多次优化调整降低 AI 率

### 3.5 Prompt 模板选择

Prompt 模板可指导 AI 生成的风格和格式：

1. 点击「选择模板」下拉框
2. 查看可用模板列表
3. 公有模板由管理员创建，所有人可用
4. 私有模板为个人创建，仅自己可用
5. 选择模板后，系统按模板风格生成

### 3.6 知识库参考

选择知识库可为生成提供参考资料：

1. 点击「选择知识库」下拉框
2. 选择已上传的知识库
3. 系统从知识库检索相关内容
4. 生成的公文将参考知识库内容

### 3.7 历史记录

公文写作记录保存在历史会话中：

1. 每次生成自动保存会话记录
2. 可在「会话历史」页面查看
3. 支持重新打开继续编辑

## 4. 会议助手模块

### 4.1 功能入口

进入「会议管理」页面开始管理会议。

路径：`/meeting/meetings/manage`

### 4.2 创建会议

#### 4.2.1 会议信息

| 输入项 | 说明 | 是否必填 |
|--------|------|----------|
| **会议标题** | 会议名称 | 必填 |
| **会议日期** | 会议召开日期 | 必填 |
| **会议地点** | 会议召开地点 | 可选 |
| **主持人** | 会议主持人 | 可选 |
| **参会人员** | 参会人员名单 | 可选 |
| **会议链接** | 线上会议链接 | 可选 |

#### 4.2.2 创建步骤

1. 点击「创建会议」按钮
2. 填写会议信息表单
3. 点击「提交」保存会议
4. 会议创建成功后显示在列表中

### 4.3 上传音频

#### 4.3.1 音频格式

支持以下音频格式：

| 格式 | 说明 |
|------|------|
| **MP3** | 常用音频格式 |
| **WAV** | 无损音频格式 |
| **M4A** | Apple 音频格式 |
| **FLAC** | 无损压缩格式 |

#### 4.3.2 上传步骤

1. 在会议详情页点击「上传音频」
2. 选择音频文件
3. 选择转写提供商：
   - **本地 ASR**：使用 Qwen ASR，适合一般场景
   - **火山引擎 ASR**：专业语音转写，支持实时流式
4. 点击「上传」提交

### 4.4 音频转写

#### 4.4.1 转写流程

**方式一：实时录音转写**

1. 进入会议详情页
2. 点击「开始录音」按钮
3. 系统通过 WebSocket 实时连接 ASR 服务
4. 说话内容实时显示在转写区域
5. 录音结束后自动保存音频文件
6. 转写文本自动保存

**方式二：上传音频转写**

1. 上传音频文件后
2. 系统自动创建转写任务
3. 后台异步处理转写
4. 可在音频列表查看处理状态
5. 完成后显示转写文本

#### 4.4.2 转写状态

| 状态 | 说明 |
|------|------|
| pending | 任务等待处理 |
| processing | 正在转写中 |
| completed | 转写已完成 |
| failed | 转写失败，查看错误信息 |
| cancelled | 已取消处理 |

#### 4.4.3 取消转写

正在进行的转写任务可取消：

1. 点击「取消处理」按钮
2. 系统终止当前转写任务
3. 已转写的内容保留

#### 4.4.4 轮询查看进度

上传音频后需轮询查看处理进度：

1. 定期刷新纪要页面
2. 查看音频状态变化
3. 状态变为 completed 后可查看完整转写

### 4.5 会议纪要生成

#### 4.5.1 纪要内容

系统自动生成以下纪要内容：

| 内容 | 说明 |
|------|------|
| **摘要** | 会议内容摘要，包含标题和正文 |
| **待办事项** | 提取的待办任务，包含执行人和时间 |
| **转写文本** | 完整的语音转写文本 |
| **说话人分段** | 区分不同说话人的发言（火山引擎） |

#### 4.5.2 本地纪要生成

使用本地 ASR（Qwen）生成纪要：

1. 完成音频转写后
2. 点击「生成纪要」按钮
3. 系统调用 LLM 分析转写文本
4. 自动生成摘要和待办事项
5. 生成完成后自动保存历史快照

#### 4.5.3 火山引擎妙记

使用火山引擎语音妙记服务：

1. 上传音频文件（volc provider）
2. 点击「提交妙记任务」按钮
3. 系统提交离线转写任务到火山引擎
4. 后台轮询任务进度
5. 完成后获取：
   - 精准转写文本
   - 说话人分段信息
   - 智能摘要
   - 待办事项提取

#### 4.5.4 取消妙记任务

正在进行的妙记任务可取消：

1. 点击「取消任务」按钮
2. 系统向火山引擎发送取消请求
3. 任务状态变为 cancelled

#### 4.5.5 纪要查看

1. 在会议详情页点击「纪要」标签
2. 查看摘要内容
3. 查看待办事项列表
4. 查看转写文本
5. 火山纪要还可查看说话人分段

#### 4.5.3 纪要编辑

1. 点击「编辑」进入编辑模式
2. 修改摘要内容
3. 添加/删除/修改待办事项
4. 点击「保存」保存修改

### 4.6 会议历史

每次纪要生成自动保存历史快照：

1. 查看「会话历史」标签
2. 选择历史快照版本
3. 查看当时的纪要内容
4. 可恢复到历史版本

### 4.7 音频管理

#### 4.7.1 音频列表

在会议详情页查看已上传的音频：

| 信息 | 说明 |
|------|------|
| 文件名 | 音频文件名 |
| 提供商 | local 或 volc |
| 文件类型 | 音频格式 |
| 状态 | 上传/处理状态 |
| 上传时间 | 上传日期 |

#### 4.7.2 音频下载

下载已上传的音频文件：

1. 在音频列表点击「下载」按钮
2. 系统从对象存储获取文件
3. 浏览器自动下载

#### 4.7.3 音频删除

删除音频文件：

1. 点击「删除」按钮
2. 确认删除操作
3. 同时删除对象存储中的文件
4. 关联的纪要数据保留

#### 4.7.4 上传任务轮询

异步上传的任务需轮询状态：

1. 上传后返回任务 ID
2. 定期查询任务状态
3. 状态变为 completed 后可用音频

### 4.8 导出纪要

支持导出纪要文件：

| 格式 | 说明 |
|------|------|
| **Word** | 导出 DOCX 文件 |
| **PDF** | 导出 PDF 文件 |
| **文本** | 导出 TXT 文件 |

## 5. 知识库管理

### 5.1 功能入口

进入「知识库」页面管理文档资源。

路径：`/doc/AI/knowledge-base`

### 5.2 创建知识库

#### 5.2.1 知识库信息

| 输入项 | 说明 | 是否必填 |
|--------|------|----------|
| **知识库名称** | 知识库显示名称 | 必填 |
| **知识库标识** | 唯一标识符 | 必填 |
| **描述** | 知识库描述 | 可选 |
| **权限类型** | 公有/私有 | 必填 |

#### 5.2.2 权限说明

| 权限类型 | 说明 |
|----------|------|
| **公有** | 所有用户可查看和使用，管理员创建 |
| **私有** | 仅创建者可查看和使用 |

#### 5.2.3 创建步骤

1. 点击「创建知识库」按钮
2. 填写知识库信息
3. 选择权限类型
4. 点击「提交」创建

### 5.3 上传文件

#### 5.3.1 支持格式

| 格式 | 说明 |
|------|------|
| **PDF** | PDF 文档 |
| **Word** | DOCX 文档 |
| **PPT** | PowerPoint 文档 |
| **文本** | TXT 文件 |

#### 5.3.2 上传步骤

1. 进入知识库详情页
2. 点击「上传文件」按钮
3. 选择文件并上传

1. 解析文档内容

| 信息 | 说明 |

| 操作 | 说明 |
|------|------|
| **查看详情** | 查看文件分块内容 |
| **下载** | 下载原始文件 |
| **删除** | 删除文件及向量 |
| **移动** | 移动到其他知识库 |

### 5.5 批量操作

支持批量文件管理：

1. 选择多个文件（勾选）
2. 点击「批量删除」
3. 确认删除操作

### 5.6 知识库使用

知识库可用于：

- RAG 问答检索
- 公文生成参考
- 会议纪要参考

## 6. 会话历史管理

### 6.1 功能入口

进入「会话历史」页面查看问答记录。

路径：`/doc/AI/conversation-history`

### 6.2 会话列表

展示所有历史会话记录：

| 信息 | 说明 |
|------|------|
| **查询内容** | 用户输入的问题 |
| **回答内容** | AI 生成的答案 |
| **来源** | 参考的文档来源 |
| **时间** | 会话创建时间 |
| **反馈** | 点赞/点踩状态 |

### 6.3 会话详情

点击会话查看详情：

1. 查看完整问答内容
2. 查看参考来源列表
3. 查看来源文档片段

### 6.4 反馈管理

对会话进行反馈评价：

| 操作 | 说明 |
|------|------|
| **点赞** | 标记会话有价值，提高权重 |
| **点踩** | 标记会话有问题，降低权重 |
| **权重调整** | 手动设置权重值 |

反馈影响：

- 点赞的会话在检索时优先返回
- 高权重会话更容易被引用

### 6.5 会话搜索

支持向量搜索历史会话：

1. 输入搜索关键词
2. 系统进行语义匹配
3. 返回相似的历史会话

### 6.6 统计信息

查看会话统计数据：

| 统计项 | 说明 |
|------|------|
| **总会话数** | 会话记录总数 |
| **点赞数** | 获得点赞的会话数 |
| **平均权重** | 平均权重值 |

## 7. Prompt 模板管理

### 7.1 功能入口

进入「Prompt 管理」页面管理提示词模板。

路径：`/doc/AI/prompt-manager`

### 7.2 模板列表

展示所有可用模板：

| 信息 | 说明 |
|------|------|
| **模板名称** | 模板显示名称 |
| **分类** | 模板分类 |
| **描述** | 模板说明 |
| **状态** | 启用/禁用 |
| **权限** | 公有/私有 |

### 7.3 创建模板

#### 7.3.1 模板信息

| 输入项 | 说明 | 是否必填 |
|--------|------|----------|
| **模板名称** | 显示名称 | 必填 |
| **分类** | 模板分类 | 必填 |
| **描述** | 模板说明 | 可选 |
| **模板内容** | 提示词内容 | 必填 |
| **变量列表** | 可替换变量 | 可选 |
| **权限类型** | 公有/私有 | 必填 |

#### 7.3.2 变量定义

模板可包含变量，使用时动态替换：

```
模板示例：
请按照以下要求撰写{{document_type}}：
标题：{{title}}
要求：{{requirement}}

变量：document_type, title, requirement
```

#### 7.3.3 创建步骤

1. 点击「创建模板」按钮
2. 填写模板信息
3. 编写模板内容
4. 定义变量列表
5. 选择权限类型
6. 点击「提交」创建

### 7.4 编辑模板

1. 点击模板的「编辑」按钮
2. 修改模板内容
3. 更新变量列表
4. 点击「保存」

### 7.5 启用/禁用

切换模板状态：

1. 点击「启用/禁用」按钮
2. 禁用的模板不可选择使用
3. 启用后恢复可用

### 7.6 删除模板

删除模板：

1. 点击「删除」按钮
2. 确认删除操作
3. 模板及关联数据删除

支持批量删除：

1. 选择多个模板
2. 点击「批量删除」
3. 确认删除

### 7.7 Prompt 分类说明

Prompt 模板按公文类型分类：

| 分类 | 适用场景 |
|------|----------|
| notice | 通知类公文 |
| bulletin | 公告类公文 |
| request | 请示类公文 |

## 9. 常见问题

### 9.1 登录问题

**Q: 无法登录系统？**

A: 请检查以下原因：
- 用户名或密码输入错误
- 账户被禁用，联系管理员
- Token 过期，重新登录

**Q: 如何获取登录 Ticket？**

A: 联系管理员，管理员可在用户管理页面为您创建 Ticket。

**Q: 首次登录提示设置密码？**

A: 您是通过 Ticket 免密登录的新用户，需设置密码才能正常使用。

### 9.2 公文写作问题

**Q: 公文生成速度慢？**

A: 公文生成需要调用 AI 模型，可能需要几秒到几十秒，请耐心等待。

**Q: 生成的公文不符合要求？**

A: 建议：
- 详细填写需求描述
- 选择合适的 Prompt 模板
- 选择相关知识库提供参考
- 多次优化调整

**Q: AI 率过高怎么办？**

A: 建议：
- 使用「优化」功能调整
- 手动编辑修改部分内容
- 增加个人风格的表达

### 9.3 会议助手问题

**Q: 音频转写失败？**

A: 请检查：
- 音频文件格式是否支持
- 音频文件是否损坏
- 网络连接是否正常
- 后端服务是否正常运行

**Q: 转写结果不准确？**

A: 建议：
- 使用火山引擎 ASR，准确性更高
- 确保音频质量良好
- 减少背景噪音

**Q: 会议纪要生成时间过长？**

A: 纪要生成依赖转写完成后进行，请等待转写完成后再查看纪要。

### 9.4 知识库问题

**Q: 文件上传后看不到内容？**

A: 文件需要解析和向量化处理，请等待处理完成后刷新页面。

**Q: 知识库检索不到相关内容？**

A: 请检查：
- 文件是否已完成处理
- 检索关键词是否匹配内容
- 知识库是否被选中

**Q: 如何创建公有知识库？**

A: 公有知识库仅管理员可创建，普通用户只能创建私有知识库。

### 9.5 会议助手问题

**Q: 音频上传失败怎么办？**

A: 请检查：
- 音频文件格式是否支持（MP3、WAV、M4A、FLAC）
- 文件大小是否超过限制（默认100MB）
- 网络连接是否稳定
- 服务器是否正常运行

**Q: 火山妙记任务一直处理中？**

A: 火山妙记是离线任务，需要一定时间：
- 一般音频需要5-15分钟处理
- 长音频可能需要更长时间
- 可定期刷新页面查看状态
- 如长时间未完成，可尝试取消重新提交

**Q: 如何取消正在进行的转写/纪要任务？**

A: 在纪要页面点击「取消处理」或「取消任务」按钮即可。

**Q: 本地 ASR 和火山 ASR 有什么区别？**

A: 
- **本地 ASR（Qwen）**：使用本地部署的 ASR 服务，适合一般场景
- **火山引擎 ASR**：使用火山引擎专业语音服务，准确率更高，支持说话人识别

### 9.6 其他问题

**Q: 页面加载慢？**

A: 请检查：
- 网络连接速度
- 浏览器缓存
- 刷新页面重试

**Q: 功能菜单看不到？**

A: 根据入口不同，功能菜单不同：
- 公文写作入口显示公文相关功能
- 会议助手入口显示会议相关功能

**Q: 如何联系技术支持？**

A: 请联系系统管理员或技术支持团队获取帮助。
