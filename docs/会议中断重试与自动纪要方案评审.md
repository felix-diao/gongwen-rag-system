### 1.1 commit 48b1541 — 断连续传后端聚合

**核心设计：引入 `recording_session_id` 概念**

```
用户开始录音 → 前端生成 recording_session_id（UUID）
  │
  ├─ WS 连接 #1 → VolcAsrSession #1 → 保存为 part_xxx_1.wav
  │   └─ （暂停 / 切后台 / 网络抖动）WS 断开 → _finalize() 保存片段

  │   └─ VolcAsrSession #2 → 保存为 part_xxx_2.wav
  │
  └─ 用户点击"结束录音" → WS 连接 #N, explicit_stop=True
```

### 1.2 commit ae69382 — WebSocket 断连处理

**核心改动：提取 `_safe_send_json()` 方法**

```python
async def _safe_send_json(self, payload: dict) -> bool:
    if not self._ws_alive:
        return False
    try:
        await self._ws.send_json(payload)
        return True
    except (WebSocketDisconnect, ClientDisconnected, ConnectionClosed):
        self._ws_alive = False
        logger.info("... 前端 WebSocket 已断开，停止推送 ...")
        return False
```

- **消除分散的 `if self._ws_alive` 判断**：所有 `send_json` 调用统一走 `_safe_send_json`
- **两端同步**：`LiveVolcAsrHandler` 和 `LiveLocalAsrHandler` 都应用了此模式
- **效果**：前端断连时后端不再抛未处理异常，优雅静默停止推送

### 2.2 存在的问题 / 功能缺口

#### 问题 1：火山 ASR 连接失败没有重试

`_recv_asr_result()` 收到火山错误帧时直接 `raise RuntimeError`：

```python
# app/services/meeting_minute_volc_service.py line 1788
raise RuntimeError(err_text)
```

这个异常在 `run()` 的 `except Exception` 里被捕获后直接标 `failed` 并重新抛出，**没有任何重试**。

实际场景中，火山 ASR 的 WebSocket 可能因：
- 服务端临时过载返回错误帧
- 网络抖动导致 WS 连接断开
- 大模型队列排队超时

这些临时性错误应该指数退避重试，而非直接标记失败。

#### 问题 2：「放弃录制」无法被检测

这是**最大的功能缺口**——后端无法区分以下两种场景：

| 场景                         | 用户意图 | 应该做什么          |
| ---------------------------- | -------- | ------------------- |
| 用户暂停、切后台，稍后会回来 | 继续录音 | 保持片段，等待重连  |
| 用户直接划掉企微（退出应用） | 放弃录音 | 自动合并 + 生成纪要 |

当前的实现：两种情况都走"只保存片段，等待后续合并"的路径。如果用户退出企微不再回来，那些片段就永远留在磁盘上，**纪要永远不会生成**。

#### 问题 3：`run()` 异常后没有兜底纪要

```python
# line 1711-1718
except Exception as exc:
    asr_session.status = "failed"
    asr_session.stream_transcript_text = "".join(self._transcript_parts)
    asr_session.error_msg = str(exc)
    self._db.commit()
    await self._safe_send_json({"type": "error", "message": str(exc)})
    raise
```

转写文本其实已保存到 `stream_transcript_text`，但状态是 `failed`，**没有触发纪要生成**。符合需求中的"即使失败了也可以把之前的录音生成会议纪要"，但目前未实现。

#### 问题 4：Local ASR 不支持断连续传

`LocalAsrSession` 表没有 `recording_session_id` 和 `audio_part_path` 字段，`LiveLocalAsrHandler` 也没有对应的合并逻辑。如果用 local provider，断连后片段数据就丢了，两条链路能力不对齐。

### 4.2 改动1：火山 ASR 连接重试

**文件**：`app/services/meeting_minute_volc_service.py`

**思路**：将 `run()` 里的 ASR 核心循环抽为 `_do_asr_loop()`，外层包指数退避重试：

```python
async def run(self) -> None:
    """实时 ASR 主流程，带火山连接重试。"""
    self._service._assert_meeting_exists(self._db, self._meeting_id)
    await self._ws.accept()

    asr_session = database.VolcAsrSession(
        meeting_id=self._meeting_id,
        status="processing",
    )
    self._db.add(asr_session)
    self._db.commit()
    self._db.refresh(asr_session)
    self._session_id = asr_session.id
    await self._safe_send_json({"type": "session_created", "session_id": self._session_id})

    max_retries = getattr(settings, 'VOLC_ASR_MAX_RETRIES', 3)
    last_exc: Optional[Exception] = None

    for attempt in range(max_retries):
        try:
            await self._do_asr_loop()  # ← 抽出来的核心：建火山 WS + forward + recv
            last_exc = None
            break  # 成功
        except (aiohttp.ClientError, RuntimeError, asyncio.TimeoutError) as exc:
            last_exc = exc
            if attempt < max_retries - 1:
                delay = 2 ** attempt  # 1s → 2s → 4s
                logger.warning(
                    "火山 ASR 连接失败，%d 秒后重试 (%d/%d) meeting_id=%s session_id=%s error=%s",
                    delay, attempt + 1, max_retries, self._meeting_id, self._session_id, exc,
                )
                await self._safe_send_json({
                    "type": "reconnecting",
                    "attempt": attempt + 1,
                    "max_retries": max_retries,
                    "delay_seconds": delay,
                })
                await asyncio.sleep(delay)
                continue

    if last_exc is not None:
        # 重试耗尽，标记失败
        asr_session.status = "failed"
        asr_session.stream_transcript_text = "".join(self._transcript_parts)
        asr_session.error_msg = str(last_exc)
        self._db.commit()
        await self._safe_send_json({"type": "error", "message": str(last_exc)})

        # ★ 兜底：即使失败，如果有录音数据就尝试生成纪要
        if self._audio_chunks:
            await self._finalize_with_auto_minutes(asr_session)
        raise
```

**要点**：
- `_do_asr_loop()` 就是把现在 `run()` 里 `try` 块中间的火山 WS 建连 + forward + recv 逻辑抽出来
- 只对网络/ASR 相关异常重试，`ValueError`（业务校验失败，如会议不存在）不重试
- 重试时发 `reconnecting` 事件通知前端，让 UI 能展示状态
- 重试间隔用指数退避（1s → 2s → 4s），总等待不超过 7s

### 4.3 改动2：超时放弃检测 + 自动完成

**新建文件**：`app/services/recording_abandon_checker.py`

**核心逻辑**：后台定时任务，扫描「超时未重连」的 recording_session，自动合并并触发纪要生成。

```python
"""超时放弃检测：长时间未重连的录音 session 自动完成并生成纪要。"""

import asyncio
import logging
from datetime import datetime, timedelta
from typing import Dict, List

from sqlalchemy.orm import Session

from app.config import settings
from app.models import database
from app.services.meeting_audio_service import meeting_audio_service
from app.services.meeting_minute_volc_service import volc_meeting_minute_service
from app.services.websocket_manager import meeting_ws_manager

logger = logging.getLogger("recording_abandon_checker")

# 默认超时：15 分钟
_ABANDON_TIMEOUT_MINUTES = getattr(settings, 'RECORDING_ABANDON_TIMEOUT_MINUTES', 15)
# 扫描间隔：2 分钟
_SCAN_INTERVAL_SECONDS = getattr(settings, 'RECORDING_ABANDON_SCAN_INTERVAL', 120)


async def _auto_complete_recording(db: Session, recording_session_id: str, meeting_id: int):
    """
    将放弃的录音自动完成：
    1. 合并所有 WAV 片段
    2. 上传到 TOS
    3. 提交妙记任务生成纪要
    4. 通过 WebSocket 广播通知前端
    """
    from pathlib import Path
    import os

    from app.services.meeting_minute_volc_service import _merge_wav_files

    sessions = (
        db.query(database.VolcAsrSession)
        .filter(
            database.VolcAsrSession.recording_session_id == recording_session_id,
            database.VolcAsrSession.status == "completed",
        )
        .order_by(database.VolcAsrSession.created_at.asc())
        .all()
    )

    if not sessions:
        return

    # 1. 收集片段文件 & 聚合转写
    wav_dir = Path(settings.VOLC_ASR_AUDIO_SAVE_DIR or os.path.join(settings.UPLOAD_DIR, "asr_recordings"))
    part_paths = []
    transcript_parts = []
    for s in sessions:
        if s.audio_part_path and Path(s.audio_part_path).exists():
            part_paths.append(Path(s.audio_part_path))
        if s.stream_transcript_text:
            transcript_parts.append(s.stream_transcript_text)

    if not part_paths:
        logger.warning("放弃录音无可用片段 recording_session_id=%s", recording_session_id)
        return

    # 2. 合并 WAV
    merged_path = wav_dir / f"meeting_{meeting_id}_recording_{recording_session_id}_auto_merged.wav"
    _merge_wav_files(part_paths, merged_path)

    # 3. 上传 TOS
    try:
        creator_id = sessions[0].creator_id if hasattr(sessions[0], 'creator_id') else None
        audio_record = meeting_audio_service.create_audio_from_path(
            db=db,
            meeting_id=meeting_id,
            provider="volc",
            creator_id=creator_id,
            source_path=merged_path,
            file_name=f"recording_{recording_session_id}_auto.wav",
            content_type="audio/wav",
        )
    finally:
        try:
            merged_path.unlink(missing_ok=True)
        except OSError:
            pass

    # 4. 回填关联 & 清理碎片
    merged_transcript = "".join(transcript_parts)
    for s in sessions:
        s.source_audio_id = audio_record.id
    db.commit()

    for p in part_paths:
        try:
            p.unlink(missing_ok=True)
        except OSError:
            pass

    logger.info(
        "放弃录音自动完成 recording_session_id=%s meeting_id=%s audio_id=%s duration=%.3f",
        recording_session_id, meeting_id, audio_record.id,
        audio_record.duration_seconds or 0,
    )

    # 5. 自动提交纪要
    try:
        volc_meeting_minute_service.submit_minutes(
            db=db, meeting_id=meeting_id, audio_id=audio_record.id,
        )
        logger.info("放弃录音自动提交纪要成功 meeting_id=%s audio_id=%s", meeting_id, audio_record.id)
    except Exception as e:
        logger.error("放弃录音自动提交纪要失败 meeting_id=%s audio_id=%s error=%s",
                     meeting_id, audio_record.id, e)

    # 6. 通知前端
    meeting_ws_manager.notify_from_thread(
        meeting_id,
        {
            "type": "recording_auto_completed",
            "meeting_id": meeting_id,
            "audio_id": audio_record.id,
            "recording_session_id": recording_session_id,
            "reason": "abandon_timeout",
            "transcript": merged_transcript,
        },
    )


async def _check_abandoned_recordings_once():
    """单次扫描超时放弃的录音。"""
    db = database.SessionLocal()
    try:
        cutoff = datetime.utcnow() - timedelta(minutes=_ABANDON_TIMEOUT_MINUTES)

        # 找：最新 ASR session 距今超时，且未合并的 recording
        abandoned = (
            db.query(database.VolcAsrSession)
            .filter(
                database.VolcAsrSession.recording_session_id.isnot(None),
                database.VolcAsrSession.status == "completed",
                database.VolcAsrSession.source_audio_id.is_(None),  # 未合并
                database.VolcAsrSession.created_at < cutoff,
            )
            .all()
        )

        if not abandoned:
            return

        # 按 recording_session_id 分组
        groups: Dict[str, List[database.VolcAsrSession]] = {}
        for s in abandoned:
            groups.setdefault(s.recording_session_id, []).append(s)

        for rsid, sessions in groups.items():
            # 确认：该 recording 在 cutoff 之后没有新连接
            recent_count = (
                db.query(database.VolcAsrSession)
                .filter(
                    database.VolcAsrSession.recording_session_id == rsid,
                    database.VolcAsrSession.created_at >= cutoff,
                )
                .count()
            )
            if recent_count > 0:
                continue  # 还在活跃，不处理

            meeting_id = sessions[0].meeting_id
            try:
                await _auto_complete_recording(db, rsid, meeting_id)
            except Exception as e:
                logger.exception("自动完成放弃录音失败 recording_session_id=%s error=%s", rsid, e)
    finally:
        db.close()


async def run_abandon_checker(stop_event: asyncio.Event):
    """后台定时循环。在 lifespan 中启动。"""
    logger.info(
        "录音放弃检测器已启动 timeout=%dmin scan_interval=%ds",
        _ABANDON_TIMEOUT_MINUTES, _SCAN_INTERVAL_SECONDS,
    )
    while not stop_event.is_set():
        try:
            await _check_abandoned_recordings_once()
        except Exception:
            logger.exception("录音放弃检测器扫描异常")
        # 分段 sleep，响应 stop 信号
        for _ in range(_SCAN_INTERVAL_SECONDS):
            if stop_event.is_set():
                break
            await asyncio.sleep(1)
```

**在 `app/main.py` lifespan 中注册**：

```python
from app.services.recording_abandon_checker import run_abandon_checker

@asynccontextmanager
async def lifespan(app: FastAPI):
    # ... 现有初始化 ...

    stop_event = asyncio.Event()
    abandon_task = asyncio.create_task(run_abandon_checker(stop_event))

    yield

    # shutdown
    stop_event.set()
    abandon_task.cancel()
    try:
        await abandon_task
    except asyncio.CancelledError:
        pass
```

### 4.4 改动3：兜底纪要生成

当 `run()` 异常后或者自动完成时，如果音频已上传，应自动触发纪要生成。上层逻辑本质上就是调用已有的 `submit_minutes` / `generate_minutes`：

```python
async def _finalize_with_auto_minutes(self, asr_session):
    """
    异常/超时场景的兜底收尾：
    如果还有 PCM 数据，就落盘 WAV 并上传，然后尝试提交纪要。
    """
    if not self._audio_chunks:
        return

    wav_dir = Path(settings.VOLC_ASR_AUDIO_SAVE_DIR or os.path.join(settings.UPLOAD_DIR, "asr_recordings"))
    wav_dir.mkdir(parents=True, exist_ok=True)

    wav_path = wav_dir / f"meeting_{self._meeting_id}_session_{self._session_id}_partial.wav"
    duration = _save_pcm_as_wav(
        self._audio_chunks, wav_path,
        sample_rate=self._sample_rate,
        channels=self._channels,
        sample_width=self._sample_width,
    )

    try:
        audio_record = meeting_audio_service.create_audio_from_path(
            db=self._db,
            meeting_id=self._meeting_id,
            provider="volc",
            creator_id=self._creator_id,
            source_path=wav_path,
            file_name=f"partial_{self._session_id}.wav",
            content_type="audio/wav",
        )
    finally:
        try:
            wav_path.unlink(missing_ok=True)
        except OSError:
            pass

    asr_session.status = "completed"
    asr_session.source_audio_id = audio_record.id
    asr_session.duration_seconds = duration
    self._db.commit()

    # 自动触发纪要
    try:
        volc_meeting_minute_service.submit_minutes(
            db=self._db,
            meeting_id=self._meeting_id,
            audio_id=audio_record.id,
        )
    except Exception as e:
        logger.warning("兜底纪要提交失败 meeting_id=%s error=%s", self._meeting_id, e)
```

### 4.6 改动5：前端自动重连（前端）

前端 WebSocket 断开后：

1. **自动重连**：检测到断连后，延迟 1-3s 重新发起 WS 连接
2. **带上同一 `recording_session_id`**：在 `config` action 中传递
3. **重连状态提示**：显示"正在重新连接..."
4. **监听 `recording_auto_completed` 事件**：收到后刷新会议纪要页面

前端需要在以下情况触发重连：
- `websocket.onclose`
- `websocket.onerror`
- 网络状态变化（online/offline）
