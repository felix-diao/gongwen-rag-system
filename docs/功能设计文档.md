## 1. 项目概述

### 1.1 项目背景

AI 文档助手系统是一个面向政务办公场景的智能文档处理平台，集成了公文写作、会议助手、知识库管理等核心功能。系统采用 RAG（检索增强生成）技术，结合大语言模型（LLM），为用户提供智能化的文档生成、优化和管理服务。

### 1.2 项目目标

- 提供智能公文写作能力，支持多种公文类型
- 提供会议音频转写和纪要生成功能
- 建立企业级知识库，支持文档智能检索
- 提供会话历史管理，支持知识沉淀
- 提供灵活的 Prompt 模板管理

## 3. 功能模块设计

### 3.1 认证与用户管理模块

#### 3.1.1 功能描述

提供用户注册、登录、密码管理、Ticket 免密登录等认证功能。

#### 3.1.2 功能清单

| 功能        | 描述                        | 端点                                      |
| ----------- | --------------------------- | ----------------------------------------- |
| 用户注册    | 新用户注册，密码强度校验    | POST /api/auth/register                   |
| 用户登录    | 用户名密码登录，返回 JWT    | POST /api/auth/login                      |
| 用户信息    | 获取当前用户信息            | GET /api/auth/me                          |
| 登出        | 用户登出                    | POST /api/auth/logout                     |
| 修改密码    | 用户修改密码                | PUT /api/auth/change-password             |
| Ticket 创建 | 创建一次性登录票据 (管理员) | POST /api/auth/create-ticket              |
| Ticket 兑换 | 兑换 Ticket 获取 JWT        | POST /api/auth/redeem-ticket              |
| 重置密码    | 管理员代重置密码            | POST /api/auth/reset-password-by-username |
| 设置密码    | 新用户首次设密              | POST /api/auth/set-password               |

#### 3.1.3 认证流程

```
┌─────────────┐
│   用户请求   │
└─────────────┘
      ↓
┌─────────────┐
│ HTTPBearer  │  提取 Bearer Token
└─────────────┘
      ↓
┌─────────────┐
│ JWT 解码    │  验证签名和过期时间
└─────────────┘
      ↓
┌─────────────┐
│ 获取用户    │  返回 user_id, username, role
└─────────────┘
      ↓
┌─────────────┐
│ 权限检查    │  RBAC 权限验证
└─────────────┘
      ↓
┌─────────────┐
│   业务处理   │
└─────────────┘
```

#### 3.1.4 Ticket 免密登录流程

```
管理员创建 Ticket:
┌─────────────┐
│ 输入用户名   │
└─────────────┘
      ↓
┌─────────────┐
│ 生成 Ticket │  (UUID格式，5分钟有效)
└─────────────┘
      ↓
┌─────────────┐
│ 用户不存在   │ → 自动注册 + needs_password_setup=True
└─────────────┘
      ↓
┌─────────────┐
│ 返回 Ticket │
└─────────────┘

用户兑换 Ticket:
┌─────────────┐
│ 提供 Ticket │
└─────────────┘
      ↓
┌─────────────┐
│ 验证有效性   │  (未使用 + 未过期)
└─────────────┘
      ↓
┌─────────────┐
│ 标记已使用   │
└─────────────┘
      ↓
┌─────────────┐
│ 生成 JWT    │
└─────────────┘
      ↓
┌─────────────┐
│ needs_password_setup=true │ → 重定向到设置密码页面
└─────────────┘
```

### 3.2 RAG 检索增强生成模块

#### 3.2.1 功能描述

核心 RAG 问答功能，实现多源检索、重排序、LLM 生成的完整流程。

#### 3.2.2 RAG 流程图

```
用户查询
    │
    ↓
┌─────────────┐
│ 文本向量化   │  Embedding Service (BGE-large-zh-v1.5)
└─────────────┘
    │
    ↓
┌─────────────────────────────────────┐
│         多源并行检索                  │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ │
│  │公共文档 │ │私有文档 │ │历史会话 │ │
│  │  库     │ │  库     │ │  库     │ │
│  └─────────┘ └─────────┘ └─────────┘ │
│     (0.6)      (0.4)      (0.3)      │  权重系数
└─────────────────────────────────────┘
    │
    ↓
┌─────────────┐
│ 加权排序    │  计算综合分数
└─────────────┘
    │
    ↓
┌─────────────┐
│ Cross-Encoder │  可选：精确重排序
│   重排序      │
└─────────────┘
    │
    ↓
┌─────────────┐
│ 构建上下文   │  Token Limit: 3000
└─────────────┘
    │
    ↓
┌─────────────┐
│  LLM 生成   │  调用外部 LLM API
└─────────────┘
    │
    ↓
┌─────────────┐
│ 创建会话记录 │  向量化入库
└─────────────┘
    │
    ↓
返回答案
```

#### 3.2.3 功能清单

| 功能          | 描述             | 端点                                      |
| ------------- | ---------------- | ----------------------------------------- |
| 标准 RAG 问答 | 同步返回完整答案 | POST /api/rag/query                       |
| 流式 RAG 问答 | SSE 流式返回答案 | POST /api/rag/stream                      |
| 调试接口      | 返回完整检索候选 | POST /api/rag/retrieve_and_generate_debug |


## 6. 安全设计

### 6.1 认证安全

#### 6.1.1 JWT 配置

| 配置项   | 值                           | 说明         |
| -------- | ---------------------------- | ------------ |
| 算法     | HS256                        | 哈希算法     |
| Secret   | settings.SECRET_KEY          | 签名密钥     |
| 过期时间 | 1440 分钟 (24h)              | Token 有效期 |
| Payload  | user_id, username, role, exp | Token 内容   |

#### 6.1.2 密码安全

| 配置项     | 值                      | 说明           |
| ---------- | ----------------------- | -------------- |
| 哈希算法   | bcrypt                  | 密码哈希       |
| 哈希轮数   | 12                      | 计算复杂度     |
| 长度要求   | 8-72字符                | 密码长度       |
| 复杂度要求 | 大写+小写+数字+特殊符号 | 密码强度       |
| 弱密码检查 | 启用                    | 禁止常见弱密码 |

### 6.2 授权安全

#### 6.2.1 RBAC 权限模型

| 角色  | 权限范围                         |
| ----- | -------------------------------- |
| admin | 所有操作、用户管理、公有资源管理 |
| user  | 自有资源操作、公有资源只读       |

#### 6.2.2 资源访问控制

- 用户只能访问自己的私有资源
- 管理员可以访问所有资源
- 公有资源所有人可读，管理员可写
- 知识库按 is_public 字段控制权限

### 6.3 数据安全

#### 6.3.1 数据库安全

- PostgreSQL 连接使用 SSL
- 数据库用户权限分离
- 定期自动备份（每日凌晨2点）
- 备份保留策略：7天每日 + 2周每周 + 2月每月

#### 6.3.2 文件存储安全

- MinIO/TOS 访问需要认证
- 文件 URL 使用签名链接
- 上传文件大小限制

### 6.4 传输安全

- HTTPS 加密传输
- WebSocket 使用 WSS 协议
- API 请求需要 Bearer Token

### 6.5 输入安全

- SQL 注入防护：使用 ORM
- XSS 防护：输入验证
- 文件类型验证
- 文件大小限制
